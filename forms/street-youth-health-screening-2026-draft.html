개요 · 개정 요약

2018년 「거리청소년 1차·2차 문진표」에 2024년 개정 청소년 위기스크리닝 척도(KYCI)의 판정 방식을 결합한 초안입니다. 1차(1쪽·35문항)는 거리 현장의 신속 확인, 2차는 심층 사정과 위기 선별, 부록은 종사자용 등급 판정·연계 기준입니다.

✓이번 개정의 핵심 7가지

  1. 거부감 없는 시작 — ‘오늘 먹은 끼니·잠·불편한 곳’ 3문항으로 시작하고, “답하기 싫으면 건너뛰어도 됩니다”를 표제부에 넣었습니다. 중간에 “여기서 멈춰도 됩니다” 지점을 두었습니다.
  2. 익명성·거부권 — 이름 대신 별명·가명, 건너뛰기·중단 권리, 불이익 없음.
  3. 만 나이와 1·2차 기준 통일(무월경 2개월), 조증 문항 보완, 오탈자·번호 중복 수정.
  4. 2026년 위험요인 — 액상형·궐련형 전자담배, 약물 오남용, 고카페인, 스마트폰 과의존, 사이버 폭력, 디지털 성범죄.
  5. 트라우마 인폼드 배치 — 성·폭력 문항을 ‘안전 및 성건강’으로 분리하고 건너뛰기 안내.
  6. 위기 스크리닝 결합 — 1차 5문항·2차 14문항은 ‘예/아니오’가 아니라 빈도·기간으로 묻습니다. 한 문항 ‘예’만으로 고위험 판정하지 않습니다.
  7. 즉시 등급 판정 — 1·2차 응답만으로 일반 / 위험 / 고위험 + Red Flag를 산출하는 판정표(부록 A-2)와 참고용 자동 계산기를 넣었습니다.

!사용 방법

  • 화면 위 탭으로 1차·2차·부록을 오갑니다. 예 / 아니오 또는 보기를 눌러 표시하면 인쇄에 ✓로 나옵니다.
  • [전체 인쇄]는 1차·2차·부록을 A4로 차례로 인쇄합니다. 1차는 1쪽에 맞췄습니다.
  • 부록 맨 위의 참고 등급 계산기가 현재 표시된 응답으로 위험요인 점수와 위기등급을 계산합니다. 최종 판단은 종사자가 합니다.

위9개정척도나를 챙겨 주는 어른이 없다고 느낀다(밥·병원·옷).

A-3낙인·편견을 만들지 않는 원칙

  • 가족의 ‘사실’을 낙인으로 쓰지 않는다 — 부모의 형 집행, 이혼·별거 자체는 위험요인 점수로 계산하지 않습니다. 실제로 청소년에게 영향을 주는 관계와 돌봄의 상태를 봅니다(KYCI 2024 개정에서 삭제).
  • 능력 대신 상황을 묻는다 — “이해력이 부족하다” 대신 “안내를 따라가기 어렵다”, “집중이 어렵다”.
  • 행위를 낙인 없이 부른다 — “성매매” 대신 “돈이나 잠자리를 받고 성관계”, “비행” 대신 “학교·생활에서의 어려움”.
  • 가출 프레임을 완화한다 — “집 밖에서 지내는 상황”으로 묻고, 주거의 안정 여부를 함께 봅니다.
  • 결과는 청소년과 함께 연다 — 등급·점수를 청소년 앞에서 읽지 않고, “우리가 같이 볼 내용”으로 설명합니다. 가명·건너뛰기·중단권은 끝까지 유지됩니다.

A-5응급 대응 6단계 (현장)

  1. 안전 확보 — 2인 1조, 이동형 버스 문 닫고 주변 정리, 흉기·약·날카로운 물건 분리.
  2. 119 신고 — 위치(도로명·건물·차량번호), 의식·호흡·출혈·복용 약, 나이·성별.
  3. 응급처치 — 출혈은 직접 압박, 골절 의심은 고정 후 이동, 의식 있으면 눕히고 체온 유지. 먹거나 마시게 하지 않기.
  4. 동행 — 응급실 이동 시 종사자 1명 동행, 신분·보험 정보·복용 약 지참.
  5. 기록 — 발견 시각, 상태, 조치, 이송 병원, 담당 의료진 이름을 당일 기록.
  6. 보고·사후 — 쉼터장 즉시 보고, 48시간 내 사례회의, 퇴원 후 1주·1개월 추적.

A-7친권자 미동의·연락 두절 시 유의점

  • 기본 원칙 — 미성년자 진료·검사·수술·정신과 입원은 실무상 법정대리인(친권자) 동의가 전제입니다. 지연 가능성을 청소년에게 미리 설명합니다.
  • 생명이 위급한 응급상황 — 응급환자 진료는 동의 여부와 무관하게 우선합니다(응급의료에 관한 법률). 사후 보호자 연락 시도 기록을 남깁니다.
  • 친권자 연락 두절 — 시·군·구 청소년 담당 부서와 경찰의 협조를 요청하고, 아동복지법상 응급조치·보호 절차를 검토합니다. 쉼터장 명의 사실 확인서·경위서를 준비합니다.
  • 정신과 입원이 필요할 때 — 자·타해 위험이 있으면 행정입원 절차(정신건강복지법)를 검토합니다. 시·군·구 정신건강 담당 공무원·정신건강전문요원의 협조가 필요하며, 종사자가 임의로 진행하지 않습니다.
  • 성폭력·성매매 피해 청소년 — 해바라기센터·1366과 동의 범위를 확인하고, 보호자에게 알리는 시점과 범위는 청소년과 상의합니다.
  • 기록 — 동의 요청·거절·연락 시도(시각·상대·결과)를 모두 남깁니다.

  1. 위기등급 준거 검증 — 이 초안의 위험요인 14문항은 KYCI 27문항을 거리 현장용으로 줄인 단축형입니다. 점수 구간(0~2 / 3~4 / 5+)은 문항 수에 비례해 조정한 잠정치이므로, 청소년상담복지센터와 협의해 타당화하거나 정식 27문항 척도로 교차 확인해야 합니다.
  2. 법령 조문 확인 — 응급의료·정신건강복지법(행정입원)·아동복지법(응급조치)·청소년복지 지원법 조문 번호와 최신 개정을 기관 법률 검토 또는 관할청 확인으로 확정.
  3. 연계처 확정 — A-12 표를 의정부 지역 실제 담당자·직통번호로 채우고 협약병원·치과·해바라기센터 협약 범위 확인.
  4. 문항 검토 — 신규·개정 문항을 청소년 자문 3~5명과 실무자 회의에서 검토. 특히 1차 24~28, 7-13·7-14, 4-33의 표현 수위.
  5. 개인정보·IRB — 문진 결과를 연구·통계로 활용할 경우 기관 IRB 또는 개인정보 영향 검토. 백혜정(2022) 연구도 법정대리인 동의 면제를 IRB 승인으로 처리한 선례가 있음.
  6. 인쇄·배포 형태 — 1차 1쪽 유지 여부(현장에서 2쪽 허용 가능), 청소년이 직접 읽는 경우 10pt 이상, 점자·큰글씨·쉬운 글 버전 필요 여부.
  7. 표준 가이드라인 연계 — 건강특화형 이동일시쉼터 3곳 공통 적용을 목표로 문진표·판정표·연계 절차를 묶어 운영 지침(안)으로 확장.
